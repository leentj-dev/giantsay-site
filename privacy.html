개인정보처리방침

시행일: 2026-10-28

1. 이 앱이 하는 일

GiantSay 앱은 채널 운영자가 만든 영상을 운영자 본인의 YouTube 채널(@giantsay-1)에 업로드하고 예약 공개하기 위해 YouTube Data API를 사용합니다. 요청하는 권한은 영상 업로드(youtube.upload)와 채널 정보 읽기(youtube.readonly)뿐입니다.

2. 수집하는 정보

이 앱은 일반 이용자의 개인정보를 수집하지 않습니다. 운영자 본인이 동의해 발급된 인증 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 전송하거나 제3자와 공유하지 않습니다.

3. 이용과 제공

Google 사용자 데이터는 위 1의 목적에만 쓰고, 광고나 판매, 제3자 제공, 분석 용도로 쓰지 않습니다. 이 앱의 Google API 이용은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 따릅니다.

4. 보관과 삭제

토큰은 운영자가 언제든 삭제할 수 있고, Google 계정 권한 페이지에서 앱의 접근 권한을 철회할 수 있습니다.

5. 문의

YouTube 채널 @giantsay-1의 커뮤니티 또는 채널 정보 페이지로 문의해 주세요.
